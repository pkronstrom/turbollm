# turbollm Raycast Extension

A [Raycast](https://raycast.com) extension for running and monitoring turbollm workflows.

## Commands

- **Run Turbollm Workflow** — Pick a workflow from the list, fill in params, and run it.

## Setup

Full setup instructions will be added in T-27. For now:

```bash
cd tools/raycast-turbo
npm install
ray develop
```
